PSYDUCK

文件即数据 · Git 即状态 · Psy 是之上的薄封装

Psyduck 是一个轻量级 SPEC 生命周期管理框架，专为 Claude Code 工作流设计。 它只管 spec 的生命周期——内容生成交给 superpowers 等技能。 单二进制、零运行时依赖、零网络调用、零 LLM 依赖——只读写 .psy/ 目录和各 package 的 SPEC.md。

📜

SPEC 即文档

每个代码包自动维护一份 SPEC.md——标准 Markdown + YAML front-matter， grep 友好，Git 可追踪。文档只记录现实，不写期望。

🔄

变更集同步

/psy-sync 在每次实施完成后自动更新受影响包的 spec， 将设计文档归档到 .psy/。归档是 git mv，不是复制。

⚡

零侵入架构

不改源码、不加依赖、不联网、不调 LLM。 Go 单二进制，跨平台，psy init 即用。 薄到几乎不存在，但一旦拥有就回不去。

psyduck@spec ~ %
